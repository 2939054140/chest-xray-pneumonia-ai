# 胸部X光肺炎辅助诊疗系统

基于多模块决策级融合架构的医学影像AI辅助诊疗系统，采用 ResNet18 迁移学习实现胸部X光肺炎识别，结合 Grad-CAM 病灶可视化、诊疗指南向量检索与大模型结构化报告生成，实现「影像诊断-可解释性-临床依据-报告输出」的全链路闭环。

## 技术架构
- **影像诊断模块**：PyTorch + ResNet18 迁移学习，二分类识别肺炎/正常，输出置信度
- **可解释性模块**：Grad-CAM 类激活热力图，可视化模型关注的病灶区域
- **知识库模块**：LangChain + Chroma 向量数据库，基于语义检索《社区获得性肺炎诊疗指南》原文
- **报告生成模块**：DeepSeek 大模型，严格遵循规则输出结构化诊疗报告，低置信度自动触发人工复核警告
- **交互界面**：Streamlit 可视化Web界面，支持图片上传、影像对比、报告下载

## 模型性能
测试集共 624 张胸部X光影像，评估结果如下：

| 指标 | 数值 |
|------|------|
| 整体准确率 Accuracy | 90.06% |
| 肺炎精确率 Precision | 89.42% |
| 肺炎召回率 Recall | 95.38% |
| 肺炎 F1 值 | 92.31% |

> 核心优势：肺炎召回率达 95.38%，漏诊率极低，符合临床辅助诊断工具的安全优先原则。

## 核心功能
1.  胸部X光片肺炎智能识别，支持真实临床泛化场景
2.  Grad-CAM 病灶热力图可视化，提供模型决策可解释性
3.  诊疗指南语义检索，所有建议均有权威指南依据
4.  标准化四段式诊疗报告自动生成，支持导出
5.  置信度安全阈值机制，低于60%自动提示人工复核
6.  结果自动归档，热力图与报告按影像文件名对应保存

## 项目结构
数据集说明

使用 Kaggle 公开数据集 Chest X-Ray Images (Pneumonia)，共 5863 张胸部 X 光灰度图，分为正常（NORMAL）与肺炎（PNEUMONIA）两类，官方划分训练 / 验证 / 测试集。

注意

本项目仅用于医学影像 AI 研究与学习演示，不构成任何临床诊断建议。
